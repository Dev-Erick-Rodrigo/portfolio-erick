# Portfólio | Erick Rodrigo

Meu site pessoal de desenvolvedor front-end.

**Ver ao vivo:** https://Dev-Erick-Rodrigo.github.io/portfolio-erick/

## O que tem no site

- Apresentação com foto e texto animado em CSS
- Seções Sobre mim, Cursos, Projetos e Contato
- Menu de navegação com rolagem suave até cada seção
- Menu para celular (botão que abre e fecha)
- Layout responsivo

## Tecnologias

- HTML5
- CSS3 (flexbox, animações e `@media` queries)
- Font Awesome e Google Fonts (Poppins)

## Como rodar

Baixe o repositório e abra o arquivo `index.html` no navegador. Não precisa instalar nada.
